# AutoBots Desktop

Official installers for **Apple Silicon Macs** and **Windows x64**.

[Download the latest desktop beta](https://github.com/yhungkevo/autobots-releases/releases)

Choose **mac-arm64.dmg** for an M-series Mac or **win-x64.exe** for Windows. No updater ZIP is required. SHA256SUMS.txt provides checksums; GitHub also displays a checksum beside each release asset.

From version 0.11.3, Settings → General → Check for Updates checks this repository, downloads the matching installer and shows progress. Choose Install & Restart when trade management is stopped. No GitHub account, token or code is required. Updates preserve the separately stored encrypted workspace. Older versions must install 0.11.3 manually once.

This repository contains installers and release notes only. The development repository remains private, and user workspaces are not hosted here. Beta installers do not yet have verified publisher signing/notarization; normal operating-system installation approval may apply. See individual release notes for validation and limitations.
